# CashFlow 💰

**Aplicação web para controle financeiro pessoal** — gerencie suas receitas, despesas e acompanhe seu saldo em tempo real com gráficos intuitivos.

[![Vercel](https://img.shields.io/badge/🔗_Acessar_App-000000?style=for-the-badge&logo=vercel&logoColor=white)](https://cashflow-eight-red.vercel.app)

---

## ✨ Funcionalidades

- 📊 **Dashboard financeiro** com visão geral do saldo
- 💳 **Controle de receitas e despesas** com categorização
- 📈 **Gráficos interativos** para análise de gastos
- 🔍 **Filtros por período e categoria**
- 📱 **Design responsivo** para desktop e mobile
- 🎯 **Metas financeiras** e acompanhamento de progresso

## 🚀 Como Executar Localmente

```bash
# Clone o repositório
git clone https://github.com/GUILHERME-LA/cashflow.git

# Acesse a pasta
cd cashflow

# Instale as dependências
npm install

# Configure as variáveis de ambiente
cp .env.example .env.local

# Inicie o servidor de desenvolvimento
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000) no navegador.
